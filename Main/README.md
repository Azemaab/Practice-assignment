Fibonacci Recursion

```java
if (n <= 1) {
    return n;
}
```
Рекурсивный случай
В рекурсивном случае функция вызывает сама себя для n минус 1 и n минус 2.
После этого результаты складываются.

```java
return fib(n - 1) + fib(n - 2);
```

Примеры

Для n = 2

```text
fib(1) + fib(0)
1 + 0 = 1
```

Для n = 3

```text
fib(2) + fib(1)
(1 + 0) + 1 = 2
```

Для n = 4

```text
fib(3) + fib(2)
2 + 1 = 3
```
