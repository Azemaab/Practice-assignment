Algorithms

В этой работе рассмотрены два алгоритма: рекурсия для чисел Фибоначчи и бинарный поиск.

 1. Fibonacci Recursion

В этой части используется рекурсия для нахождения чисел Фибоначчи.

Базовый случай

Базовый случай нужен для того, чтобы рекурсия не продолжалась бесконечно.

Если n меньше или равно 1, функция возвращает n.

```java
if (n <= 1) {
    return n;
}
```

Рекурсивный случай

Функция вызывает сама себя для n минус 1 и n минус 2. После этого результаты складываются.

```java
return fib(n - 1) + fib(n - 2);
```

Примеры

Для n = 2

```text
fib(1) + fib(0)
1 + 0 = 1
```

Для n = 3

```text
fib(2) + fib(1)
(1 + 0) + 1 = 2
```

Для n = 4

```text
fib(3) + fib(2)
2 + 1 = 3
```

Пример кода

```java
public static int fib(int n) {
    if (n <= 1) {
        return n;
    }

    return fib(n - 1) + fib(n - 2);
}
```

Недостаток

Этот способ работает медленно для больших значений n.

Одна и та же часть может вычисляться несколько раз. Например, fib(2) может вызываться несколько раз.

Поэтому сложность этого метода является экспоненциальной.

 2. Binary Search

В этой части используется бинарный поиск для поиска элемента в массиве.

 Условие

Массив обязательно должен быть отсортирован. Если массив не отсортирован, бинарный поиск работать правильно не будет.

 Как работает

Для поиска используются две границы low и high.

Сначала low указывает на первый элемент, а high на последний элемент массива.

Затем находится середина массива с помощью mid.

Если значение в середине равно искомому элементу, поиск заканчивается.

Если искомый элемент больше значения в середине, левая граница low сдвигается вправо.

Если искомый элемент меньше значения в середине, правая граница high сдвигается влево.

Таким образом, после каждой итерации половина массива отбрасывается.

Сложность алгоритма составляет O(log n).

Пример кода

```java
public static int binarySearch(int[] array, int target) {
    int low = 0;
    int high = array.length - 1;

    while (low <= high) {
        int mid = (low + high) / 2;

        if (array[mid] == target) {
            return mid;
        }

        if (array[mid] < target) {
            low = mid + 1;
        } else {
            high = mid - 1;
        }
    }

    return -1;
}
```

Пример использования:

```java
int[] array = {2, 5, 8, 12, 16, 23, 38, 56, 72, 91};

int result = binarySearch(array, 23);

System.out.println(result);
```

Результат:

```text
5
```

Это означает, что число 23 находится под индексом 5.

Пример 1

Ищем число 23.

```text
low = 0
high = 9
mid = 4
a[4] = 16
```

23 больше 16, поэтому:

```text
low = 5
```

Дальше:

```text
low = 5
high = 9
mid = 7
a[7] = 56
```

23 меньше 56, поэтому:

```text
high = 6
```

Дальше:

```text
low = 5
high = 6
mid = 5
a[5] = 23
```

Элемент найден. Его индекс равен 5.

 Пример 2

Ищем число 5.

Сначала:

```text
low = 0
high = 9
mid = 4
a[4] = 16
```

5 меньше 16, поэтому:

```text
high = 3
```

Дальше:

```text
low = 0
high = 3
mid = 1
a[1] = 5
```

Элемент найден. Его индекс равен 1.
 Пример 3

Ищем число 100.

Числа 100 нет в массиве.

Алгоритм постепенно уменьшает область поиска, пока low не станет больше high.

После этого поиск заканчивается и метод возвращает:

```text
-1
```

Это означает, что элемент не найден.
